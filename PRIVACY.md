# Privacy Policy

Effective: August 13, 2026

Conductor Swarm is a skills package containing instructions, metadata, and bundled local Python runtimes. It operates through the agent runtime in which a user installs it. The repository does not provide a hosted server, user account system, analytics service, or independent data collection endpoint.

When project learning is enabled, Loop Improvement stores milestone summaries, selected proposal text, artifact fingerprints, comparison results, and lesson decisions in the project's `.loop-improvement/lessons.sqlite3`. Keep this state out of Git and portable handoffs. Its basic input filters do not guarantee removal of sensitive information; review inputs before capture. Retirement stops lesson retrieval but retains the evidence record. Status and retrieval do not initialize missing state. Explicit evaluator commands run with the host's permissions and may have their own storage or network effects.

The skills may direct an agent to inspect files, repositories, task systems, models, tools, or connectors that the user and host runtime place in scope. Access, retention, transmission, and model-provider behavior are controlled by that runtime and the services the user connects. Conductor Swarm does not grant new permissions or bypass existing approval and authentication controls.

Do not include credentials, secrets, personal information, or proprietary content in public issues. Privacy questions may be opened through the repository's support channel.
